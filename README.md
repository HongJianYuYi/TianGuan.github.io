# 天官太乙式

> 以《史记·天官书》星官体系为骨，参七政四余排星之法，在浏览器中起一张中式星盘。
> 究天人之际 · 通古今之变 · 成一家之言

**在线访问**：<https://hongjianyuyi.github.io/TianGuan.github.io/>

纯静态前端，无构建步骤、无第三方运行时依赖，可直接双击 `index.html` 或托管于 GitHub Pages。

---

## 一、功能概览

页面分为三个并列工作区 + 页头 + 页脚，三栏下边界对齐（`align-items: stretch`）。

### 页头

- 印信方框内嵌甲骨文「星」字（方正甲骨文单字子集，woff2 仅 1.2 KB，不依赖系统字体）。
- 大标题「天官太乙式」，副标题「究天人之际 · 通古今之变 · 成一家之言」（语出司马迁《报任安书》）。

### 输入区 · 钦若昊天·敬授民时

（语出《尚书·尧典》：「乃命羲和，钦若昊天，历象日月星辰，敬授民时。」）

- **三历知一推二**：公历 / 农历 / 干支历，任改其一即推其余二者。
- **真太阳时**：北京时间 + 地平经差（经度×4 分钟）+ 均时差；日柱以真太阳时 23:00 换日。
- **省—市—区三级选经纬度**：内置 34 省 / 393 市 / 2874 区县中心经纬度；境外可手填经纬度。
- **干支**：年柱以立春为界，月柱以节为界，日柱 `(JDN+49) % 60`，时柱五鼠遁。

### 式盘区 · 璇玑玉衡·以齐七政

（语出《尚书·舜典》：「在璇玑玉衡，以齐七政。」）

盘面由内而外四层：

1. **紫微宫**：北斗七星（天枢、天璇、天玑、天权、玉衡、开阳、摇光），斗魁四边形**不闭合**（天枢与天权不连线），斗柄随斗建旋转。
2. **七政行度层**：日月五星按视黄经入宿，标注星名与宿度。
3. **十二地支 / 十二次分野层**：十二次以宿界为界，「二十八宿入十二地支」自然成立。
4. **二十八宿环**：按古宿度分度，标七曜配属、四方星象（青龙、玄武、白虎、朱雀）。

盘式约定：上南下北、左东右西；地支自午中顺时针，二十八宿循黄经东行故盘上逆时针，合「宿东行、支西转」。

### 占验区 · 观乎天文·以察时变

（语出《易·贲卦·彖传》：「观乎天文，以察时变。」）

- **七政数据表**：星名、视黄经、入宿、宿度、入次分野、黄道宫位。
- **斗建时序**：`农历月建地支，月将地支将神名。太阳入X宿Y度，斗柄指Z（月建）。`
  - 月将 = 与月建六合之地支（如九月建戌 → 卯将太冲）。
  - 十二月将神：子神后、丑大吉、寅功曹、卯太冲、辰天罡、巳太乙、午胜光、未小吉、申传送、酉从魁、戌河魁、亥登明。
- **占验记录**：存于本机 `localStorage`，不联网。

### 输出

「存为图片」把页头、输入摘要、式盘、占验表与记录合成为一张 2 倍分辨率 PNG（1240×1710）下载。

## 三、算法要点

### 时间系统

- 北京时间 → 儒略日（JD）。
- 真太阳时 = 北京时间 + (经度 − 120°) × 4 分钟 + 均时差。
- 日柱以真太阳时 23:00 换日（子时换日，非 0 点）。
- 年柱以**立春**为界，月柱以**节**为界（非中气）。

### 节气

按太阳视黄经 15° 等分，用 Newton 迭代反解交节时刻。
**民历惯例**：交节当日即属该节气，即使交节时刻尚未到来（修正了 10 月 23 日霜降差一天的问题）。

### 农历

1900–2100 年用位压缩月表展开为「定朔月」，与公历双向检索。闰月、大小月以表为准。

### 七政（日月五星）

采用 Schlyter 低精度行星算法，木土二星加摄动修正。
经与 `astronomy-engine`（VSOP87 / ELP）对照校验，日月五星视黄经误差 **≤ 0.7 角分**，满足星盘格局判断。

### 斗建（斗柄指月建）

- 以太阳视黄经定月：315° 起寅，每 30° 进一支。
- 斗柄在该支扇区内按节气进度线性推进，故斗柄所指与月支始终一致。
- 斗建算法以太阳黄经为锚，不依赖人工查表。

### 二十八宿古度

- 古度合计 365.25 度（与回归年同），按 365.25 归一到 360°。
- 角宿锚定角宿一（Spica，J2000 视黄经 203.84°）。
- 岁差 50.29″/年，逐年平移宿界。

### 分野

十二次以宿界为界，故二十八宿自然落入十二地支，无须额外映射。

### 方位约定

- 盘面：上南下北、左东右西。
- 地支：自午中起顺时针（午→未→申→…→巳）。
- 二十八宿：循黄经自西向东行，盘上逆时针（角→亢→氐→…）。
- 二者方向相反，正合「宿东行、支西转」的传统盘式。

## 四、工程笔记

### 字体：甲骨文「星」内置化

印信方框需显示甲骨文「星」字。直接依赖 `font-family: "甲骨文"` 不可靠——甲骨文字形多在 PUA 私用区，且访客电脑未必安装。

方案：

1. 获取方正甲骨文 TTF（免费商用，收字 1430）。
2. 用 `pyftsubset` 提取单字 U+661F，压成 woff2，仅 **1.2 KB**：
   ```bash
   pyftsubset 方正甲骨文.TTF --unicodes=U+661F --flavor=woff2 \
     --output-file=fonts/fz-jiaguwen-xing.woff2 --no-hinting --desubroutinize
   ```
3. CSS 用 `@font-face` 引入，`.seal` 字体栈首选 `OracleXing`。
4. 字号 32px、正常字重、不加描边（甲骨文本为单刀刻辞，过粗失真）。

### 布局：三栏等高对齐

`.grid` 用 CSS Grid，`align-items: stretch` 确保三栏下边界齐平。
断点：1560px → 340/1fr/372；1320px → 占验区跨全行；860px → 单列。

式盘 SVG 用 `width:100%; height:auto; max-width:1060px`，由容器宽度自适应。

### 缓存破坏

所有静态资源（CSS / JS）加查询参数版本号（如 `?v=1.0.7`），部署后强制刷新缓存。

### 导出长图

`export.js` 用内联 SVG 重新排版（不依赖 html2canvas），输出 2 倍分辨率 PNG，保证印刷级清晰度。

## 五、使用说明

### 本地运行

双击 `index.html` 即可（部分浏览器对 `file://` 的字体加载有限制，建议用本地服务器）：

```bash
python -m http.server 8765
# 访问 http://localhost:8765
```

### 操作提示

- **三历联动**：改公历推农历干支；改农历推公历干支；改干支反推公历（±34 年内取最近匹配）。
- **时辰下拉**：先移动时刻再反查日期。
- **真太阳时**：选省市区后自动算经纬度；境外可手动输入经度。
- **占验记录**：自动存入 `localStorage`，清除浏览器数据即丢失。

## 六、部署到 GitHub Pages

1. 将本目录推送到仓库根目录。
2. 仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`。
3. 等待部署完成，访问 `https://<用户名>.github.io/<仓库名>/`。

## 七、已知边界

| 项目 | 范围 / 精度 |
|---|---|
| 农历 | 1900–2100，表外推步受限 |
| 节气 | 与现代天文年历可能相差数分钟 |
| 七政 | 低精度算法，误差 ≤ 0.7 角分，不作精密历算 |
| 干支反推 | 当前年 ±34 年内逐日匹配 |
| 字体 | 仅「星」字内置甲骨文，其余为系统衬线字体 |
