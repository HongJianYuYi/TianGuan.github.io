## 摘要

本文介绍「天官太乙式」的设计与实现：一套以《史记·天官书》星官体系为骨架、以现代天文算法为推步引擎的**实星占验**（observational astrology）星盘。与七政四余等星命术不同，本盘动者惟七曜（日、月、五星），静者为二十八宿、十二支、十二次，一切度量归赤道一系——赤道宿度为先秦至明初之正法，黄经坐标迟至明末《崇祯历书》方为官方主流。系统在纯静态浏览器环境内完成：公历、农历、干支历三历互推与真太阳时定时；日月五星视位置（经 VSOP87/ELP 级实现对照，误差 ≤0.7′）；70 颗恒星的 J2000 星表经 IAU 1976 岁差当日化；入宿度、凌犯守掩、七政互合、五星聚舍、占候位态、昏旦可见性等占验判据一遵《开元占经》口径；并备昏旦中星、斗柄昏时实指与地平圈寻星盘三件观测工具。全部功能离线可用（PWA），可整页合成 2 倍分辨率 PNG 案例图。

**关键词**：天官书；二十八宿；岁差；凌犯守掩；昏旦中星；赤道坐标；Service Worker

## 一、引言

中国星占分两系：一系演为七政四余星命，推人休咎；一系守《天官书》旧贯，察天文以验时政——后者必以**实星**为据：某曜入某宿几度、犯某星、守某官，皆当期可验之于天。历代《天文志》所书「荧惑守心」「月入太微」「五星聚东井」之属，皆此系之物。

然今之可用工具，或为西式黄逍十二宫星盘，或为神煞排盘软件，鲜有以汉家赤道宿度为体、以现代星历为用者。本工作填补此隙：以《汉书·律历志》古宿度与次度表为骨架，以依巴谷/SIMBAD 恒星数据与成熟行星算法为推步，使两千年之岁差漂移（今距星与汉宿界之差达 −2° 至 +6.5°）在盘面上如实呈现，令「古法之界」与「今测之星」同盘互见。

## 二、文献依据与体系裁定

### 2.1 坐标裁定：归赤道一系

判宿、入宿度、次界、支界一律用**赤经**；七政运动、节气、月相、交食等动力计算用黄经，再经黄赤转换归赤道。此裁定据赤道宿度为汉家正法之史实，并消「黄道宫」等后起或域外之物（四余、神煞、黄道十二宫一概不纳）。

### 2.3 岁差之痕

汉度宿界固定于古度比例，今测距星则以岁差当日化落位，二者之差盘面自见：十二次界穿宿而过、支扇宽窄不等、距星未必恰在「本宿 0 度」。此不修不齐，正是本盘之旨——**岁差不是噪声，而是两千年体系漂移的证据**。

## 三、历法与时间系统

- **三历互推**：公历、农历（1900–2100 位压缩定朔月表）、干支历知一推二；干支反推在 ±34 年内取最近匹配。
- **真太阳时** = 标准时 + 地平经差（经度每度 4 分）+ 均时差；日柱以真太阳时 23:00 换日；年柱立春为界、月柱以节为界、时柱五鼠遁。
- **力学时**：UT→TT 用 Espenak–Meeus ΔT 分段多项式，2015–2050 段由实测约 69 s 向多项式平滑过渡；一切位置计算先转 TT。
- **节气**：太阳视黄经 15° 等分，Newton 迭代反解交节时刻，误差约数分钟。
- **月相**：日月视黄经差 Newton 迭代求真朔望时刻；十八小时内书「月近朔 / 月近望」（近望缀「暗星难见」）。
- **行政区**：内置 34 省 / 393 市 / 2874 区县中心经纬度求地方时；境外可手填。

## 四、天体位置计算

- **七政**：Schlyter 低精度行星算法加木土摄动修正，月球取 12+5 项摄动；与 `astronomy-engine`（VSOP87/ELP 级）对照，日月五星视黄经误差 **≤0.7′**（角分）。
- **黄赤转换**：ε = 23.4392911° − 0.0130042°·T；α、δ 由标准球面公式给出。
- **行度**：jd ±0.25 日差分 × 2 得瞬时黄经速度；|v| ≤ 0.015°/日为留，v<0 为逆；伏限辰星 18°、太白 11°、外行星 15°。

## 五、恒星数据与坐标当日化

- **星表**（`stars.js`）：70 颗——二十八宿距星 28 + 星占名星（心宿二、大角、天狼、老人、织女、河鼓、北极五星、贯索、五帝座等）+ v1.16.0 补三垣要星 24 颗（太微垣左右执法、东西上相次相、东次将；三台；天市垣帝座、侯、宗正一、左右垣诸国），皆 ≤3.9 等目视可见之星，证认从《仪象考成》通行制。J2000.0 平位置静态内置，不联网。
- **岁差当日化**：IAU 1976（Lieske）三分量旋转，±200 年优于 1″；与角宿一黄经岁差→黄赤转换路径互验，当日赤经差约 0.04′。
- **地平坐标**：地方恒星时 + 观测经纬度 → 高度角/方位角（方位自北顺时针）；日出日落由太阳高度扫描（10 分钟步长）加二分细化（约 2 s），极昼极夜自动略去。

## 六、占验判据体系

### 6.1 入宿
入宿度 =（星赤经 − 宿始赤经）/ 宿宽 × 宿古度，七政与恒星同口径。

### 6.2 凌犯守掩与七政互合
haversine 球面角距，阈值见 2.2 表；七政两两互判同口径，主动方取行度快者（故多书「太阴犯某」「太白犯某」）；日不判（昼不可见）。每曜取最近一事入占候列，斗建时序按角距升序列至四事。

### 6.3 五星聚舍
五纬（辰、太白、荧惑、岁、填）同宿为聚，三、四、五星皆书（如「三星聚于斗」）。

### 6.4 占候位态
无事之日书位态，皆黄经差所断：内行星合 / 晨见 / 夕见 / 东西大距（阈值 asin(a(1+e))：辰星 27.8°、太白 46.7°，±2.5° 窗）；外行星冲（|E|>165°）/ 东西方照；太阴朔弦望。

### 6.5 昏旦可见性标注
古法占候皆昏旦夜观：太阳高度 > −6° 书「昼不见」，−12° 至 −6° 书「昏可见 / 旦可见」（依上下半场），< −12° 书「夜可见」；任一天体在地平线下书「地平线下」。出口三处：斗建时序、占候列悬停、聚舍括注。

## 七、观测工具

- **昏旦中星**：斗建时序书「昏中某（某宿），旦中某（某宿）」，可与《月令》中星表对照，直观见岁差之痕。
- **斗柄昏时实指**：天极→摇光大圆以 ENU 向量法延至地平求交点化十二支（近天顶方位角法失稳，故用向量法）；今岁实校春寅、夏午、秋申、冬亥——各晚汉制一支。盘底注记与斗建占法并存，两不相混。
- **地平圈寻星盘**：式盘区「占星 / 寻星」切换。方位—高度投影（半径线性映高度，外圈地平、心为天顶，虚线为 30°/60° 高度圈），南上北下、东左西右，面南仰观即今夜实天；70 恒星、七政、北斗实况（勺形连线）按此刻地平坐标投出，地平线下不画。式盘内盘之北斗为斗建符号，寻星盘之北斗为实星，两义分置。
- **星点提示**：悬停与点击皆可（触屏无悬停，点击出浮层）——星名、拜耳名、星等、入宿度、高度方位；四等以上注「暗星，城郭难见」。
- **时间步进**：± 一日 / ± 一时四钮，跨月跨年自滚，可逐时逐日观凌犯守掩之生成消散。

## 八、工程实现

- **架构**：纯静态原生 HTML/CSS/JS，无构建、无第三方运行时依赖；IIFE 模块挂 `window.TGData/TGAstro/TGCal/TGChart/TGExport`；全部资源以 `?v=x.y.z` 破缓存。
- **渲染**：式盘与寻星盘皆手写 SVG（切向/径向排字、古度比例楔形、命中区透明圆）；页面载入三栏依次浮现，`prefers-reduced-motion` 自动关闭动画。
- **导出**：任何含 foreignObject 的 SVG 必污染 canvas（三例实测皆 taint），故导出为**纯 SVG 按页面版式复刻**——版式手写、内容实时取自 DOM、盘面复用 `TGChart.svg(c)`，2 倍分辨率 PNG，文件名 `天官太乙式_YYYYMMDD_HHmm.png`；推步区按钮等推演之具不入图。
- **字体与图标**：甲骨文「星」由方正甲骨文 TTF（免费商用）经 `pyftsubset` 提 U+661F 单字压 woff2（1.2 KB）内置；字形矢量轮廓以 fontTools SVGPathPen 提取，供页头印信、favicon 与 PWA 图标复用；PWA 位图图标（192/512/maskable-512）由该矢量印信经 canvas 栅格化生成。
- **PWA**（v1.19.x）：manifest（start_url/scope 相对写法，自适应 Pages 子路径）+ Service Worker 缓存三轨——导航 network-first、带 `?v=` 资源 cache-first（query 即版本指纹，与强刷机制相容）、字体图标 stale-while-revalidate；cache 名版本化 `tgty-x.y.z`，activate 清旧版，skipWaiting + clientsClaim。**升版约定三连改**：`index.html` 的 `?v=` → `sw.js` 的 CACHE 与 CORE 清单 → 本记录。
