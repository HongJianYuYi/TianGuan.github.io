> 以《史记·天官书》星官体系为骨的**实星占验**星盘：全历归赤道一系，七政以当日赤经入宿，
> 十二次从《汉书·律历志》次度表，分野从《晋书·天文志》，斗建月将、行度庙旺、月相交食一遵古法。
>
> 究天人之际 · 通古今之变 · 成一家之言

**在线访问**：<https://hongjianyuyi.github.io/TianGuan.github.io/>

可直接双击 `index.html`，或托管于任意静态服务器（GitHub Pages 等）。

## 一、体系纲要（学术口径）

本盘非七政四余之星命术，而是《天官书》一系的**实星占验**：动者惟七曜（日月五星），
静者为二十八宿、十二支、十二次。全部度量遵汉家旧制——**赤道坐标**（赤道宿度为先秦至明初正法，
黄经坐标迟至明末《崇祯历书》方为官方主流）。

| 层 | 口径 | 出处 |
|---|---|---|
| 二十八宿宿度 | 古度合计 365.25°，归一至 360° | 《汉书·律历志》三统历 |
| 宿环锚点 | 角宿一（Spica）**当日赤经**，岁差 50.29″/年 平移 | 实测＋岁差 |
| 七政入宿 | 当日**赤经**判宿，盘面亦按赤经落位 | 古法 |
| 十二次 | 次度表：寿星初轸十二度、大火初氐五度……界穿宿而过、弧宽不等（30–31.25 古度） | 《汉书·律历志》 |
| 十二支扇区 | 随宿环归并同支之宿，宽窄不等，与次环脱钩——岁差漂移盘面自见 | 式盘旧制 |
| 分野 | 州 · 国并举（如「兖州 · 郑」） | 《晋书·天文志》州郡躔次 |
| 中宫 | 「中宫天极星」，北斗按 J2000 实测赤道坐标投影成形 | 《史记·天官书》 |
| 月将 | 太阳过宫（中气换将），十二月将神名如六壬式 | 式法 |
| 亮度（庙旺平落陷） | 七曜五行 × 所临赤道地支五行生克 | 星命古法移用于赤道支 |
| 行度（顺逆留伏） | 顺逆留以日行黄经差分为断；伏以距日角距为断 | 《开元占经》五星法 |
| 交食 | 朔望视日月黄经差，食限视月纬 | 古法食限之近似 |

**不纳入**：四余（罗计月孛）、神煞、十二黄道宫——皆后起或域外之物，与实星体系异贯。

## 二、页面与功能

页面为页头 + 三栏（推步 / 式盘 / 占验）+ 页脚，三栏下边界对齐。

### 页头

- 印信方框内嵌甲骨文「星」字（方正甲骨文单字子集 woff2，仅 1.2 KB，不依赖访客系统字体）。
- 大标题「天官太乙式」；副标题「究天人之际 · 通古今之变 · 成一家之言」（《报任安书》）。
- 浏览器标签页图标 / 桌面快捷方式图标即此印（favicon.svg 矢量字形 + apple-touch-icon.png）。

### 推步区 · 钦若昊天 · 敬授民时（《尚书·尧典》）

- **三历知一推二**：公历 / 农历 / 干支历，任改其一即推其余。
- **真太阳时**：北京时间 + 地平经差（经度每度 4 分钟）+ 均时差；日柱以真太阳时 23:00 换日。
- **方位**：省—市—区三级内置 34 省 / 393 市 / 2874 区县中心经纬度；境外可手填。
- **干支**：年柱以立春为界，月柱以节为界，日柱 `(JDN+49) % 60`，时柱五鼠遁；干支反推在 ±34 年内取最近匹配。

### 式盘区 · 璇玑玉衡 · 以齐七政（《尚书·舜典》）

由内而外：

1. **中宫天极星**：北辰居中（「北辰不动 · 众星拱之」），北斗七星按真实星形连属
  （斗魁不闭合——天枢天权本无连线），斗柄随斗建旋转，盘心示「斗柄指 X · 某月建 X」。
2. **七政行度层**：七政按当日赤经落位，引线标注星名，环带刻度每 10°。
3. **十二支扇区 + 十二次环**：支字居中，次名与州名沿汉志次度表的不等分弧界布列。
4. **二十八宿环**：古度分度，宿名 + 七曜配属 + 五古度细刻，外缘标四方星象（青龙、玄武、白虎、朱雀）。

盘式：上南下北、左东右西；地支自午中顺时针，宿循赤经东行故盘上逆时针，合「宿东行、支西转」。

### 占验区 · 观乎天文 · 以察时变（《易·贲卦·彖传》）

- **七政表（八列）**：星曜 → 亮度 → 行度 → 赤经 → 星次 → 入宿 → 宿度 → 分野。
  列序之旨：体（是谁）→ 性（强弱）→ 行（顺逆）→ 位（坐标）→ 次 → 宿 → 度 → 野（归属）。
  - **亮度**：庙旺平落陷，按星与所临赤道支之五行生克（庙＝宫生星，旺＝星克宫，平＝同，落＝宫克星，陷＝星生宫），五色分等，悬停示其理。
  - **行度**：顺 / 逆 / 留 / 伏（伏者示距日度分），逆染朱、留染黄、伏染青灰。
  - **星次**：星所坐之支的次名（星纪、玄枵……析木）。
  - **分野**：州 · 国。
- **斗建时序**：`某月建某，某将某神。太阳入某宿某度，斗柄指某（月建）。……朔/弦/望，某食可期。`
  月将以太阳过宫为断；月相由日月黄经差定；交食以月纬食限提示「可期」。
- **断语记录**：存于本机 `localStorage`，不联网。

### 输出

「存为图片」将页头、推步摘要、式盘、占验表、斗建时序、断语合成为 2 倍分辨率 PNG
（纯 SVG 按页面版式复刻，非截图重排），文件名 `天官太乙式_YYYYMMDD_HHmm.png`。

## 四、算法要点

### 时间与历法

- 北京时间 → 儒略日（JD）；真太阳时 = 北京时间 + (经度 − 120°) × 4 分 + 均时差。
- 节气按太阳视黄经 15° 等分，Newton 迭代反解交节时刻；交节当日即属该节气（民历惯例）。
- 农历 1900–2100 年位压缩月表展开为定朔月，与公历双向检索。
- 日柱真太阳时 23:00 换日；年柱立春为界；月柱以节为界。

### 七政位置

- Schlyter 低精度行星算法，木土加摄动修正；经 `astronomy-engine`（VSOP87/ELP）对照，
  日月五星视黄经误差 **≤ 0.7 角分**。
- 黄赤转换：ε = 23.4392911° − 0.0130042°·T；
  α = atan2(sin λ·cos ε − tan β·sin ε, cos λ)，δ = asin(sin β·cos ε + cos β·sin ε·sin λ)。

### 宿、次、支

- 宿环锚点 = 角宿一当日赤经（J2000 视黄经 203.84° 随岁差平移，再以当日交角转赤道）。
- 入宿度 = (星赤经 − 宿始赤经) / 宿宽 × 宿古度。
- 次弧沿宿环按次度表累计古度定位，与支扇区各自独立。

### 行度与交食

- 日行差分：jd ± 0.5 日黄经差。v < −0.01°/日 为逆，|v| ≤ 0.03°/日 为留，余为顺。
- 伏限（距日角距）：辰星 18°、太白 11°、外行星 15°；月与日不判伏。
- 月相：日月黄经差定朔（0±22.5°）、上弦（90）、望（180）、下弦（270）。
- 食限：朔且 |月纬| < 1.4° → 日食可期；望且 |月纬| < 1.1° → 月食可期。

## 五、工程笔记

### 甲骨文「星」内置

甲骨文字形多在 PUA 私用区且访客未必装字体，故：

1. 方正甲骨文 TTF（免费商用）→ `pyftsubset` 提 U+661F 单字压 woff2（1.2 KB）；
2. `@font-face` 引入，印信字号 32px、正常字重、无描边（单刀刻辞，过粗失真）；
3. 另以 fontTools SVGPathPen 提取字形矢量轮廓（UPM=1000），供导出图页头与 favicon.svg 复用；
4. apple-touch-icon.png 由 TTF 直接栅化（PIL）。

### 导出：为什么不是截图

- `file://` 下浏览器禁 fetch 本地文件（曾报「Failed to fetch」）；
- 更根本：**任何含 foreignObject 的 SVG 图像一律污染 canvas**（三例实测全 taint），
  DOM 克隆方案彻底不可行。
- 故 export.js 为**纯 SVG 按页面版式复刻**：版式（页头/三栏/页脚）手写，
  内容（读数、表格、斗建时序、断语）实时取自 DOM，式盘直接复用 `TGChart.svg(c)`。
  代价：界面改版后导出列宽、配色需手工同步（列序、庙旺五色、行度四色均已对齐）。

### 缓存与样式

- 所有静态资源带 `?v=x.y.z` 查询参数，部署后强刷生效。
- 三栏 Grid `align-items: stretch` 等高；断点 1560 / 1320 / 860。
- 表格自然宽度、窄屏横向滑动；全局暗色细滚动条（webkit + Firefox 双写），消灭原生白框。
- 载入三栏依次浮现（0.8s 缓出），`prefers-reduced-motion` 下自动关闭动画。

## 六、使用说明

```bash
python -m http.server 8765
# 访问 http://localhost:8765
```

（双击 `index.html` 亦可运行，唯 `file://` 下字体与导出在个别浏览器受限，建议本地服务器。）

- **三历联动**：改公历推农历干支；改农历推公历干支；改干支反推公历日期。
- **时辰**：先拨时刻，再反查日期。
- **真太阳时**：选省市区自动算；境外手填经纬度。
- **断语记录**：自动存入 `localStorage`，清除浏览器数据即丢失。
- **存为图片**：当前盘面合成 PNG 下载。
